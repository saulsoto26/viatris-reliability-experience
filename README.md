# Viatris Reliability Experience: C-8 and C-11

Interactive presentation by VisualK for Viatris Reliability, Vega Baja. Single self-contained `index.html`: no build step, no external dependencies.

- **Desktop / projector:** open in full screen (F). Arrows or Space to advance; G scene map; E explore mode; S presenter view.
- **Phone / tablet:** reflowing mobile layout; swipe or use the bottom bar. Can be installed to the home screen and works offline after the first visit.

**Confidential.** Contains client maintenance data. Keep the repository private and share the link only with authorized people. `robots.txt` and a `noindex` tag discourage search indexing but are not access control.

To update: replace `index.html` and bump the cache name in `sw.js` (`vk-rx-v1` → `vk-rx-v2`).
